## 🌟 Highlights & Features

- **Cyber-Sleek Dark Theme**: Built with custom CSS variables, subtle glassmorphism cards, and emerald-neon glow accents.
- **Hero Showcase**: Features a glowing profile card with floating status badges and an interactive role-typing animation.
- **Instant Resume Download & Preview**: One-click direct PDF download with tactile visual feedback plus browser preview mode.
- **Responsive Layout**: Designed mobile-first, ensuring smooth navigation and aesthetics across mobile, tablet, and desktop screens.
- **Vanilla Tech Stack**: High performance and ultra-fast loading without heavy external framework dependencies.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (Custom Design System, Flexbox, Grid), JavaScript (ES6+)
- **Typography**: [Outfit](https://fonts.google.com/specimen/Outfit) & [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono)
- **Deployment**: GitHub Pages (Continuous Deployment)

## 🚀 Running Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/layakpatel7-lab/my-portfolio.git
   ```

2. **Navigate to the directory**:
   ```bash
   cd my-portfolio
   ```

3. **Open `index.html`** in your browser, or run a local server:
   ```bash
   python -m http.server 3000
   ```
   Visit `http://localhost:3000`.
